## GitHub Desktop 安裝／更新
1. 先以 GitHub Desktop 選取原網站儲存庫，Repository → Show in Explorer，先備份整個資料夾。
2. 將這個 ZIP 解壓縮後的全部內容（不要連外層資料夾）複製到原儲存庫根目錄，覆蓋同名檔。
3. 參考 `舊檔刪除清單.txt`，從儲存庫根目錄刪除清單中的舊檔（若存在）；GitHub Desktop 會將這些列為 Deleted。
4. 在 Changes 確認檔案，Commit to main，然後 Push origin。
5. 開啟 GitHub Pages，確認首頁顯示 V1.8.74；在首頁點「動漫圖庫驗收」，逐張測試圖檔。

> ZIP 解壓後覆蓋不會自動移除原儲存庫中的舊檔；刪除步驟必須另外進行。切勿刪除 `.git` 資料夾。
> 不要清除瀏覽器網站資料，以免失去孩子未備份的作品與收藏。
